## Distribuição Uniforme ($U(-3, 7)$)

Intervalo de comprimento 10. FDP: $f(x)=1/10$.

**a)** **FDA:** $F(x) = \frac{x-(-3)}{7-(-3)} = \frac{x+3}{10}$ para $-3 \le x \le 7$. (0 para $x<-3$, 1 para $x>7$).

**b)** $P(|X-1|\le 2) = P(-1 \le X \le 3)$. Intervalo de interesse $[-1, 3]$ está no domínio. Comprimento = $3 - (-1) = 4$. Probabilidade: $4/10 = 0.4$.

**c)** $P(|X|>3) = P(X>3 \text{ ou } X<-3)$. Interseção com o domínio $(-3, 7)$ é o intervalo $(3, 7)$. Comprimento = $7 - 3 = 4$. Probabilidade: $4/10 = 0.4$.
