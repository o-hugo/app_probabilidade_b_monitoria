# Partículas alfa — Poisson com $\lambda = 3{,}2$

O número de partículas alfa emitidas por uma fonte radioativa em um intervalo de tempo fixo segue distribuição de Poisson com parâmetro $\lambda = 3{,}2$.

Calcule $P[X \leq 2]$.

---

## Solução

$$X \sim \text{Poisson}(3{,}2)$$

$$P[X \leq 2] = P[X=0] + P[X=1] + P[X=2]$$

**Calculando cada termo:**

$$P[X = 0] = \frac{e^{-3{,}2}(3{,}2)^0}{0!} = e^{-3{,}2}$$

$$P[X = 1] = \frac{e^{-3{,}2}(3{,}2)^1}{1!} = 3{,}2\,e^{-3{,}2}$$

$$P[X = 2] = \frac{e^{-3{,}2}(3{,}2)^2}{2!} = \frac{10{,}24}{2}\,e^{-3{,}2} = 5{,}12\,e^{-3{,}2}$$

**Somando:**

$$P[X \leq 2] = e^{-3{,}2}\bigl(1 + 3{,}2 + 5{,}12\bigr) = 9{,}32\,e^{-3{,}2}$$

Numericamente, $e^{-3{,}2} \approx 0{,}04076$:

$$\boxed{P[X \leq 2] = 9{,}32 \times e^{-3{,}2} \approx 9{,}32 \times 0{,}04076 \approx 0{,}3799}$$

Portanto, a probabilidade de observar no máximo 2 partículas alfa é aproximadamente **38,0%**.
