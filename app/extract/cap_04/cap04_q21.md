## Enunciado

Seja $X$ uma variável aleatória Poisson com parâmetro $\lambda$. Mostre que $P\{X=k\}$ atinge o valor máximo para $k = [\lambda]$, onde $[\lambda]$ denota o maior inteiro menor ou igual a $\lambda$.

## Solução

Analisemos a razão entre probabilidades consecutivas:

$$\frac{P\{X=k\}}{P\{X=k-1\}} = \frac{e^{-\lambda}\lambda^k/k!}{e^{-\lambda}\lambda^{k-1}/(k-1)!} = \frac{\lambda}{k}.$$

Esta razão:
- é $> 1$ quando $\lambda > k$, ou seja, $k < \lambda$
- é $= 1$ quando $\lambda = k$ (somente se $\lambda$ é inteiro)
- é $< 1$ quando $\lambda < k$, ou seja, $k > \lambda$

Logo $P\{X=k\}$ é crescente para $k < \lambda$ e decrescente para $k > \lambda$.

- Se $\lambda$ **não é inteiro**: o máximo é atingido em $k = [\lambda]$ (único ponto de virada).
- Se $\lambda$ **é inteiro**: $P\{X=\lambda\} = P\{X=\lambda-1\}$ (razão = 1), e o máximo é atingido tanto em $k = \lambda$ quanto em $k = \lambda - 1$, ambos iguais a $[\lambda]$ pelo critério do enunciado. $\blacksquare$
