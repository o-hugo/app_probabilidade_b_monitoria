## Enunciado

Mostre que para uma variável aleatória $X$ com distribuição hipergeométrica de parâmetros $N$, $M$ e $n$, a variância é:

$$\text{Var}(X) = n\frac{M}{N}\frac{N-M}{N}\!\left(1 - \frac{n-1}{N-1}\right).$$

## Passo 1: Representação por indicadores

Para $i = 1, \ldots, n$, defina $I_i = 1$ se a $i$-ésima bola retirada é branca, $I_i = 0$ caso contrário. Então $X = \sum_{i=1}^n I_i$.

**Resumo:** $X$ é soma de indicadores de cada retirada ser branca.

## Passo 2: Momentos de cada indicador

Por simetria, $E[I_i] = M/N$ e $E[I_i^2] = M/N$, portanto:

$$\text{Var}(I_i) = \frac{M}{N} - \left(\frac{M}{N}\right)^2 = \frac{M}{N}\cdot\frac{N-M}{N}.$$

**Resumo:** $\text{Var}(I_i) = (M/N)(1-M/N)$.

## Passo 3: Covariância entre indicadores ($i \neq j$)

$$E[I_i I_j] = P[\text{bola } i \text{ e bola } j \text{ são brancas}] = \frac{M}{N}\cdot\frac{M-1}{N-1}.$$

$$\text{Cov}(I_i, I_j) = E[I_i I_j] - E[I_i]E[I_j] = \frac{M(M-1)}{N(N-1)} - \frac{M^2}{N^2} = -\frac{M(N-M)}{N^2(N-1)}.$$

**Resumo:** $\text{Cov}(I_i,I_j) = -M(N-M)/[N^2(N-1)]$ para $i \neq j$.

## Passo 4: Variância de $X$

$$\text{Var}(X) = \sum_{i=1}^n \text{Var}(I_i) + \sum_{i \neq j} \text{Cov}(I_i, I_j)$$

$$= n\cdot\frac{M(N-M)}{N^2} + n(n-1)\cdot\left(-\frac{M(N-M)}{N^2(N-1)}\right)$$

$$= \frac{nM(N-M)}{N^2}\left(1 - \frac{n-1}{N-1}\right) = n\frac{M}{N}\frac{N-M}{N}\left(1 - \frac{n-1}{N-1}\right). \qquad \blacksquare$$

**Resumo:** Bilinearidade da variância + covariância negativa (sem reposição) dá o fator de correção $(1-(n-1)/(N-1))$.
