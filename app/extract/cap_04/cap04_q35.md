## Enunciado

Existem $N$ figurinhas diferentes. Um colecionador compra envelopes sucessivamente, cada um contendo uma figurinha escolhida uniformemente ao acaso entre as $N$ (com reposição). Seja $X$ o número de envelopes necessários para completar a coleção.

**(a)** $X$ tem distribuição binomial negativa?

**(b)** Determine $E(X)$.

## Passo 1: Item (a) — não é binomial negativa simples

A binomial negativa pressupõe probabilidade de sucesso **constante** em todos os ensaios. Aqui, a probabilidade de obter uma figurinha **nova** muda a cada etapa: após coletar $i-1$ figurinhas distintas, a chance de obter uma nova é $(N-i+1)/N$, que depende de $i$.

Portanto, $X$ **não tem distribuição binomial negativa** — é uma soma de geométricas com parâmetros diferentes.

**Resumo:** A prob de sucesso varia, logo não é BinNeg simples.

## Passo 2: Item (b) — $E(X)$ por decomposição

Defina $T_i$ como o número de envelopes comprados para obter a $i$-ésima figurinha **nova**, dado que já se têm $i-1$ distintas. Então $X = T_1 + T_2 + \cdots + T_N$.

Cada $T_i$ é geométrica com parâmetro de sucesso $p_i = (N-i+1)/N$:

$$E[T_i] = \frac{1}{p_i} = \frac{N}{N-i+1}.$$

**Resumo:** $T_i \sim \text{Geom}(p_i)$ com $p_i = (N-i+1)/N$.

## Passo 3: Esperança total

$$E(X) = \sum_{i=1}^{N} E[T_i] = \sum_{i=1}^{N} \frac{N}{N-i+1} = N \sum_{j=1}^{N} \frac{1}{j} = N \cdot H_N,$$

onde $H_N = 1 + \frac{1}{2} + \cdots + \frac{1}{N}$ é o $N$-ésimo número harmônico.

**Resumo:** $E(X) = N H_N \approx N \ln N$ para $N$ grande.
