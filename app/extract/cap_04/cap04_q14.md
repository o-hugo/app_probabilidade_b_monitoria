# Sistema de satélites — confiabilidade sob condições climáticas

Um sistema de satélites possui $N$ componentes e funciona se **pelo menos $k$** deles estiverem operacionais. As condições climáticas afetam a confiabilidade:

- **Com chuva** (probabilidade $\alpha$): cada componente funciona com probabilidade $p_1$
- **Sem chuva** (probabilidade $1-\alpha$): cada componente funciona com probabilidade $p_2$

Os componentes funcionam independentemente. Determine a probabilidade de o sistema funcionar amanhã.

---

## Passo 1: Probabilidade condicional de funcionamento

Seja $F$ o evento "sistema funciona". Condicionando nas condições climáticas:

$$P[F] = P[F \mid \text{chuva}]\,P[\text{chuva}] + P[F \mid \text{sem chuva}]\,P[\text{sem chuva}]$$

$$P[F] = \alpha\,P[F \mid \text{chuva}] + (1-\alpha)\,P[F \mid \text{sem chuva}]$$

**Resumo:** Lei da probabilidade total condicionando no clima.

---

## Passo 2: Probabilidade em cada cenário

**Com chuva:** Seja $X \sim \text{Binomial}(N, p_1)$ o número de componentes funcionais.

$$P[F \mid \text{chuva}] = P[X \geq k] = \sum_{j=k}^{N}\binom{N}{j}p_1^j(1-p_1)^{N-j}$$

**Sem chuva:** Seja $Y \sim \text{Binomial}(N, p_2)$ o número de componentes funcionais.

$$P[F \mid \text{sem chuva}] = P[Y \geq k] = \sum_{j=k}^{N}\binom{N}{j}p_2^j(1-p_2)^{N-j}$$

**Resumo:** Ambas as probabilidades são caudas superiores de distribuições binomiais.

---

## Passo 3: Resultado final

$$\boxed{P[F] = \alpha \sum_{j=k}^{N}\binom{N}{j}p_1^j(1-p_1)^{N-j} + (1-\alpha)\sum_{j=k}^{N}\binom{N}{j}p_2^j(1-p_2)^{N-j}}$$

---

## Exemplo numérico

Para $N = 4$, $k = 3$, $\alpha = 0{,}3$, $p_1 = 0{,}7$, $p_2 = 0{,}9$:

$$P[X \geq 3] = \binom{4}{3}(0{,}7)^3(0{,}3) + (0{,}7)^4 = 4(0{,}343)(0{,}3) + 0{,}2401 = 0{,}4116 + 0{,}2401 = 0{,}6517$$

$$P[Y \geq 3] = \binom{4}{3}(0{,}9)^3(0{,}1) + (0{,}9)^4 = 4(0{,}729)(0{,}1) + 0{,}6561 = 0{,}2916 + 0{,}6561 = 0{,}9477$$

$$P[F] = 0{,}3 \times 0{,}6517 + 0{,}7 \times 0{,}9477 = 0{,}1955 + 0{,}6634 = 0{,}8589$$
