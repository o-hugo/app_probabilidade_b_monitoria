## Enunciado

Considere $X$ com distribuição binomial negativa ($R$ sucessos, parâmetro $p$). Determine $E(X)$ e $\text{Var}(X)$.

**Dica:** $X = Y_1 + Y_2 + \cdots + Y_R$, onde $Y_i$ tem distribuição geométrica de parâmetro $p$.

## Solução

Cada $Y_i$ representa o número de ensaios (inclusive o sucesso) para obter o $i$-ésimo sucesso. Aqui, $Y_i \sim \text{Geométrica}(p)$ na versão "número de ensaios até o sucesso", com $P[Y_i = k] = (1-p)^{k-1}p$ para $k = 1, 2, \ldots$, donde:

$$E[Y_i] = \frac{1}{p}, \qquad \text{Var}(Y_i) = \frac{1-p}{p^2}.$$

Como $X = Y_1 + \cdots + Y_R$ com os $Y_i$ **independentes**:

$$E(X) = \sum_{i=1}^R E[Y_i] = \frac{R}{p}.$$

$$\text{Var}(X) = \sum_{i=1}^R \text{Var}(Y_i) = \frac{R(1-p)}{p^2}. \qquad \blacksquare$$
