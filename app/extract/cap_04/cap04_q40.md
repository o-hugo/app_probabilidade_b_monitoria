## Enunciado

Seja $X$ uma variável aleatória Poisson com parâmetro $\lambda$. Qual o valor de $\lambda$ que maximiza $P\{X=k\}$, $k \geq 0$? Determine o estimador de máxima verossimilhança para $\lambda$.

## Solução

$$L(\lambda) = P\{X=k\} = \frac{e^{-\lambda}\lambda^k}{k!}.$$

Maximizar $L(\lambda)$ é equivalente a maximizar $\ell(\lambda) = \ln L(\lambda) = -\lambda + k\ln\lambda - \ln(k!)$.

Derivando e igualando a zero:

$$\ell'(\lambda) = -1 + \frac{k}{\lambda} = 0 \implies \hat{\lambda} = k.$$

Como $\ell''(\lambda) = -k/\lambda^2 < 0$, este é um máximo. O estimador de máxima verossimilhança é $\hat{\lambda} = k$ (a observação em si). $\blacksquare$
