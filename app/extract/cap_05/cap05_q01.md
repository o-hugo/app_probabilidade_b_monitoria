## Enunciado

Se $X$ é uniformemente distribuída no intervalo $(0, 20)$, calcule: (a) $P(X < 3)$; (b) $P(X > 12)$; (c) $P(4 < X < 11)$; (d) $P(|X - 3| < 4)$.

## Solução

Para $X \sim U(0,20)$, $P(a < X < b) = (b-a)/20$.

**(a)** $P(X < 3) = 3/20$.

**(b)** $P(X > 12) = (20-12)/20 = 8/20 = 2/5$.

**(c)** $P(4 < X < 11) = 7/20$.

**(d)** $|X-3| < 4 \Leftrightarrow -1 < X < 7$. Como $X > 0$: $P(0 < X < 7) = 7/20$.
